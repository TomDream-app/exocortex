# Memory

## Role

Memory is the layer that keeps captured material available for transformation.

It is not a simple archive or folder system.

In Exocortex, memory preserves material so that relations, recurrences and structures may later emerge.

## Position

capture → memory → transformation → structure → action

Capture brings material into the system.
Memory keeps it available.
Transformation activates relations.
Structure stabilizes emerging forms.
Action uses these structures for orientation and production.

## Function

Memory supports:

- conservation
- indexing
- comparison
- contextual reuse
- recurrence detection
- later transformation

## Principle

Memory must stay open enough to allow transformation, but stable enough to support return, comparison and navigation.

A memory object is not a final interpretation.
It is material kept available for future structuring.
