# Structure

## Role

Structure is the layer that stabilizes forms emerging from memory and transformation.

It is not a fixed taxonomy.

In Exocortex, structure appears when relations, recurrences or patterns become stable enough to guide navigation and action.

## Position

capture → memory → transformation → structure → action

Memory keeps material available.
Transformation activates relations.
Structure stabilizes selected forms.
Action uses these forms for orientation and production.

## Function

Structure supports:

- orientation
- navigation
- consolidation
- decision
- reuse
- future transformation

## Principle

A structure is not imposed too early.

It is recognized when material has crossed a threshold of recurrence, coherence or usefulness.
